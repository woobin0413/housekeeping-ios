# Security

Report a vulnerability through this repository's GitHub private vulnerability reporting when enabled. Keep credentials and personal data out of public issues and pull requests.

Actual configuration belongs in ignored local environment files or the hosting provider's secret settings. Templates contain placeholders. Source changes run a checksum-verified Gitleaks scan. These checks reduce accidental exposure; they do not certify that future changes are secure.

## App and backend scope

Recognition remains disabled in the production app composition. Before enabling a paid provider, configure server-side credentials, spending limits and authorization. Keep purchase photos in private storage and preserve the existing household access rules.

Validation for this publication change: 13 recognition-function tests, including cancellation of oversized chunked bodies before buffering. Existing hosted/device acceptance limitations are documented in the README.
